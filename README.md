# Productive ML

Baseline Productivity Tracker (user input determinate)

Uses user input to determine which keyword phrases are deemed "productive" or "neutral" anything labeled outside of that is determined to be a distraction

Primary function is to recommend optimal productivity time frames, essential break intervals, and distraction reminders based on likely-hood of drifting off productivity.

This also gives a weekly hourly goals adjusted by the user themselves or provided by the recommender then provides a scoring system based on the likelyhood the User achieves said goal.

PRIVACY: (THIS APP DOES NOT SEND ANY DATA OR STORE DATA OUTSIDE OF THE USER'S LOCAL MACHINE)
It stores the data locally on the user computer under the data folder when generated (written in computer binary)
